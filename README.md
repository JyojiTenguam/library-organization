# 🗂️ Library Organization

Projeto com foco na organização e manipulação de dados de uma biblioteca, utilizando JavaScript para praticar lógica de programação com `map`, `filter` e `sort`.

## ✨ Demonstração

> Este projeto não possui interface visual. As funcionalidades são voltadas à prática de lógica com dados estruturados.

## 💡 Sobre

Neste exercício, foram criadas funções para organizar e filtrar uma coleção de livros, autores e gêneros literários.

O desafio principal é aplicar as Higher Order Functions `map`, `filter` e `sort` para gerar resultados formatados e ordenados a partir dos dados disponíveis.

## 🛠️ Habilidades desenvolvidas

- Uso de Higher Order Functions como `map`, `filter` e `sort`
- Manipulação de arrays de objetos em JavaScript
- Escrita de funções com responsabilidade única
- Organização e extração de dados específicos

## 🧪 Tecnologias utilizadas

- JavaScript ES6+
- Node.js

## 🚀 Como rodar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/JyojiTenguam/library-organization.git
```

2. Acesse a pasta do projeto

```bash
cd library-organization
```
3. Instale as dependências
```bash
npm install
```
